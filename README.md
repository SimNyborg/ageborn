# Ageborn

From clubs to lasers in one battle.

Ageborn is a one-lane tug-of-war battler for the browser. Two bases face each other, your warriors march and fight on their own, turrets guard your base, and XP carries you from the Stone Age to the Future. Around the battle sits a collection game: build a War Plan with one loadout per age, open Time Capsules, upgrade cards and collect skins. Nothing is for sale, and every opponent in this version is a clearly labeled AI.

**Play:** https://simnyborg.github.io/ageborn/ (the latest build from `main`)

## Status

In development. See [docs/PROGRESS.md](docs/PROGRESS.md).

## Run locally

Requires Node.js 22.

```bash
npm install
npm run dev
```
