# social-media (orphan branch)

Content studio for the game's social account. Nothing here is part of the game build, and no workflow runs on this branch.

- `docs/BRIEF.md`: the studio brief (start here).
- `studio/`: capture and compose scripts (see `studio/README.md`).
- `queue/`: finished posts waiting to be published. Files are deleted after publishing.
- `state/`: posting log and analytics.
- `docs/`: research, publishing notes, voice recipe, the studio report.
