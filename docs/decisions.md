# Build decisions

Append-only log of decisions made where `docs/DESIGN.md` was ambiguous or had to change during the build. Add entries under your work package heading: date, the decision, and the DESIGN section it touches.

## WP0

- 2026-09-27: The repo is public and hosted on GitHub Pages (owner's choice, to keep hosting free). DESIGN B1 and C2/WP0 updated accordingly.
- 2026-09-27 (contracts): B15 `export declare function createSim / replayMatch / createBot` became the type aliases `CreateSim`, `ReplayMatch` (`src/contracts/sim.ts`) and `CreateBot` (`src/contracts/bot.ts`). A declared function in a real `.ts` module has no runtime value, so under `verbatimModuleSyntax` a value import of it would silently be `undefined`. Implementations export `const createSim: CreateSim = ...` (WP2) and `const createBot: CreateBot = ...` (WP3). Signatures are unchanged. (DESIGN B15, B10)
- 2026-09-27 (contracts): The combined B15 blocks "observation.ts and bot.ts" and "session.ts and platform.ts" are split into the separate files B14 lists. `src/contracts/index.ts` is a type-only barrel (`export type * from ...`); every contract module has zero runtime exports (a test checks this). Pixi and signals types are referenced only as type-level `import('pixi.js')` / `import('@preact/signals')`, as in B15, so the "contracts import nothing" rule (B2) holds at runtime. (DESIGN B2, B14, B15)
- 2026-09-27 (contracts): `Observation.units[].p` and `telegraphs[].p` use the same unit as `SimState` positions (milli-lu, B3), measured from the observer's gate. B15 only says "p relative to the observer". (DESIGN B3, B15)
- 2026-09-27 (fakes): `src/contracts/fakes/**` are test and dev helpers only; production code must not import them. `fakes/art.ts` imports `pixi.js` at runtime (C2/WP0 task 5 asks for Pixi Graphics rectangles), with a single `eslint-disable-next-line ageborn/layers` on that import. (DESIGN B2, C2/WP0)
- 2026-09-27 (fakes): The fake content uses the A5 table units (lu, ms, whole HP, gold), not compiled units; it is shape-correct `CompiledContent` for UI, render and wiring tests, never balance. Because `ages` and `formats` are total records, all five `AgeDef`s exist, but every fake format spans only Stone and Medieval and only those have cards. (DESIGN A2.3, B3, C2/WP0)
- 2026-09-27 (scaffold): Toolchain pins (B1). TypeScript 6.0.3, not 7.0: typescript-eslint 8.70.1 supports `typescript >=4.8.4 <6.1.0`. Vite 8.3.1 with @preact/preset-vite 2.10.6 (peer range includes Vite 8; dev and build verified). Vitest 5.0.2, ESLint 10.11.0 (typescript-eslint supports it), @playwright/test 1.56.1 because its bundled Chromium is revision 1194, the one preinstalled in cloud sessions. @types/node 22.x to match the Node 22 runtime.
- 2026-09-27 (scaffold): Layer rules (B2) are enforced by a small local ESLint rule `ageborn/layers` in `eslint.config.js` that resolves `@/` and relative specifiers to their src layer, instead of `no-restricted-imports` string patterns (which cannot tell `contracts/fakes -> ../content` from a real `content` import). `LAYER_RULES` is exported for the tests/integrity import-graph test. Package allowances not spelled out in B2: `valibot` in content and save, `fflate` in save, `@preact/signals` in capsule. Test files (`*.test.ts(x)`, `*.bench.ts`, `test/` folders) are exempt from layer and determinism rules, since for example AI tests must run the sim. `import('pixi.js')` type annotations are allowed (contracts use them for view types).
- 2026-09-27 (scaffold): Determinism lint bans float literals in sim, ai, meta, core and content, except `src/content/raw/**`, which mirrors the Part A tables exactly (compile.ts converts to integers, B4).
- 2026-09-27 (scaffold): sfc32 follows PractRand (`tmp = a + b + counter++`), seeded with four xmur3 words of `"${seed}"`, no warm-up discards. Draws return uint32; `randInt` uses rejection sampling (no modulo bias). Core offers integer `isqrt` and a degree-based `sinDegBp`/`cosDegBp` lookup table since `Math.sin/sqrt` are banned in the pure layers.
- 2026-09-27 (scaffold): i18n files are `src/i18n/<namespace>.<locale>.json`, discovered with `import.meta.glob`. Nested objects flatten to dot keys; keys are global across files (each WP prefixes its own), duplicates warn in dev and the first file (alphabetical) wins. Missing keys fall back to EN, then to the key itself. Placeholders are `{name}`.
- 2026-09-27 (scaffold): Dev pages (`src/dev/<name>/page.tsx`) default-export a Preact component and may export `title`; `?dev=1#<name>` opens one. Dev pages are internal tools and exempt from the i18n rule. The game name "Ageborn" is a brand constant, not a string key.
- 2026-09-27 (scaffold): `npm run size` (tools/size.ts) counts index.html plus the entry script, modulepreload chunks and stylesheets referenced from dist/index.html, gzipped; fails above 3 MB, warns when all of dist exceeds 8 MB. Playwright runs against `vite preview` at /ageborn/ (Chromium only for now); `PW_CHROMIUM_PATH` overrides the browser binary.

- 2026-09-27 (counter duels): The real sim (WP2) is built in parallel and has no duel entry point, so the matrix comes from a compact deterministic duel model in `src/content/counters/duel.ts` that follows A2.7 (edge ranges, soft single file with overtaking, symmetric closing, two-phase impacts, damage pipeline steps without phases or buffs, area rules, first-hit, Brace, resist, auras, heals, shields, Roar, called strikes, EMP, Time Stop, pounce, riders, death explosions). Duel-only rules: no bases, so an idle unit walks toward the nearest enemy its first attack can hit (either direction) and the bomber hovers over the nearest ground enemy; targets are re-picked at each attack start. Equal gold: both armies cost 450-1,100 gold, smallest gold gap first (≤ 5%), then closest to 700. Each pair runs both ways and the results are averaged; a duel ends when a side is wiped, after 90 s, or after 10 s without movement, attacks or damage. Abilities trigger on pre-step state and stuns apply together, so every mirror duel is exactly even. Staleness: the file stores the hash of every input (units, economy, battle, engine version, duel rules) and `src/content/test/counters.test.ts` fails when it differs; bump `DUEL_ENGINE_VERSION` when duel logic changes. Regenerate with `npx tsx tools/counters.ts` (about 10 s). Switching to the real sim later is requested in `docs/requests/wp1-counter-duel-harness.md`. (DESIGN B4, B12)

## WP2

- 2026-09-27 (content units): The sim reads `CompiledContent` in table units (ms, lu, lu/s, whole HP, gold, bp) and converts once per content object into its runtime tables (`src/sim/rules.ts`, cached in a `WeakMap`): ticks, milli-lu, milli-lu per tick, centi-HP at spawn, milli-gold. WP1 confirmed the convention (see WP1 "units"); the sim does not read `content.int`. Tests and golden replays compile `tests/fixtures/content` with the local shim `src/sim/shim.ts` (`compileForSim`); `src/sim/test/realContent.test.ts` checks that WP1's `content` yields the same sim rules as the shim. Values the contract has no field for are rules in code: Brace and air knockback resist 100%, the final-age XP cap = `economy.overchargeXp` (both 1,200), the modernise credit = `economy.sellRefundBp` (both 50%), Stampede's fallback start p = 200 (`STAMPEDE_FALLBACK_P`), mid-lane = the centre of `powerZoneClamp`. (DESIGN A2.4, A2.7, A2.8, A5.7, B3, B4)
- 2026-09-27 (units of state and events): As B3: x in milli-lu, HP/shields/damage in centi, gold/XP in milli, charge in ppm. `Observation.me.gold` is milli-gold (state units, like the fake sim); `xpBp` is XP as bp of the current threshold (final age: of the 1,200 Overcharge amount). `died.bountyGold` / `bountyXp` are the bounty before the XP cap; `goldEarned` / `xpEarned` carry what was credited. `hit.damage` is the full pipeline result (overkill included), `shieldAbsorbed` the part the shields took; `hit.heavy` = damage ≥ 15% of the victim's max HP (A12). `hit.x` is the target's x. `targetId` 0 means "no target" (ids start at 1). (DESIGN B3, B15)
- 2026-09-27 (source ids): Turrets and powers have no entity id. Turret hits and projectiles use `sourceId` / `from` = −10 − (side × 4 + mount) (`turretSourceId`, exported by `@/sim`); `turretFired` precedes its `projectileFired` in the same tick. Power hits use `sourceId` −1 with `castId` set; Last Stand hits −2 with `sourceCard` `last_stand`. For kills by powers and Last Stand `died.killerId` is null; for turret kills it is the turret source id. Called strikes (Radio Operator) are projectiles with visual `proj.shell` and `sourceKind` `ability`. (DESIGN A14.2, B15)
- 2026-09-27 (event cadence): Passive gold and XP accrue every tick but are reported once per second as one `goldEarned` / `xpEarned` (reason `passive`), to keep the stream small. Sell refunds and cancel refunds add gold without an event (the HUD reads `state`). `turretSold` and `turretReplaced` fire when the 1 s sale or modernise starts (the turret stops firing at once, the view plays the clip); the mount frees (sale) or `turretBuilt` fires (modernise) 1 s later. The Orbital Lance emits one `powerImpact` per tick of its sweep (index = tick of the sweep); Stampede one per aurochs at launch; Smoke Screen, Royal Decree, Nanite Surge and Paratroopers one at the telegraph end. `prevX` is set at the start of each tick (the position the previous tick ended at), which is what B3 step 17's interpolation bookkeeping needs. (DESIGN B3, B6)
- 2026-09-27 (distances): All "within N lu" rules between units use edge distance (A2.7: all ranges are edge distances): attack ranges, auras, heal radius, Roar, EMP, Time Stop, called-strike search, chain hops. Splash radii and barrage impacts use centre distance ("whose centre lies within the radius"). Cleave, pierce and follow-behind reach is measured from the primary's centre to the other unit's near edge, on the side away from the attacker. Line and gate-zone turrets measure edge distance from their own gate line; turret range likewise. The Orbital Lance touches a unit when the beam is within 20 lu of its edge. "Allies" never include the source (auras, heals, Roar). (DESIGN A2.6, A2.7, A5)
- 2026-09-27 (movement): Soft single file is resolved front to back per side against the planned positions of the allies ahead; the first capping ally ahead may be joined side by side (front rank) and every later one keeps (wA + wB) × 0.3. An ally caps a mover when it moved this tick or its longest range ≤ the mover's; others are passed. Enemy blocking uses pre-move positions; when the nearest enemy ahead also wants to advance, each side may take at most floor(gap / 2) (symmetric resolution). Retreats (Hold) never back into an enemy behind. Knockback, pulls and the Toad drag all use the knockback resist (Brace and air 100%, large and huge 50%) and cancel pending windups; leaping units ignore them. The Toad drag stops at the target side's frontmost ground unit and short of the dragging side's nearest ground unit ahead. Units standing still without a target report mode `hold`. (DESIGN A2.7)
- 2026-09-27 (targeting): Units keep a target within range + 20 lu leash; attacks start only in range. The base counts as a lower priority class than any unit, so at the 1 s re-check a unit hitting the base switches to an enemy unit in range. Turrets pick afresh for every shot (0% windup), `front` = nearest their gate. Grumpy Toad: nearest enemy ranged or support ground unit in range, else the second-closest small or medium ground enemy (the only one when there is one). Gravity Well aims at the densest point of its candidates' span on the 10 lu grid; the primary is the enemy nearest that point. Power auto-aim scans p 150-1,050 in 10 lu steps for the most summed enemy card cost within half the zone (ties: the p nearest the caster), mid-lane when nobody scores. (DESIGN A2.7, A2.8, A2.9, A5.2, A5.6)
- 2026-09-27 (abilities and powers): Stunned or leaping units use no abilities (auras continue). Pounce's "blocked" = an enemy ground unit ahead within its attack range; the leap takes 0.5 s, cancels windups, and the next attack 0 bites ×2. Roar needs attack 0's target in range. The Battering Ram targets the base when in range, else only enemy ground units ahead within its range. Stampede ignores the aim and starts at the caster's frontmost ground unit (p = 200 without one); Paratroopers ignore the aim and land where the cast computed (150 lu beyond the enemy front at cast time). Royal Decree and Nanite Surge apply at the telegraph end to every own unit alive then; the Nanite shield scales with the loadout multiplier, its 40% regen does not (it is already proportional to max HP) and heals on the shared 10-tick grid. Barrage, Stampede, Lance, Last Stand and death explosions are exempt from the area rule. Smoke Screen misses are rolled with the sim RNG when a projectile (or instant effect) is fired from or into an enemy cloud; missed shots still fly and emit `projectileFired` but deal nothing. Legendaries receive 50% of heals and regen. (DESIGN A2.7, A2.9, A5)
- 2026-09-27 (training): `training.trays` restricts the learner (side 0) only, so the scripted opponent trains from its full loadout; `unlockSlot` adds a slot to the event side's tray for its current age, and an age missing from `trays` is unrestricted. ## WP5

- 2026-09-27 (render API): `BattleView` (`src/render/battleView.ts`) takes `{ sim, art, audio, mySide?, settings?, feel?, isMobile?, arena?, seed?, onPresetChange? }`, where `sim` is anything with read-only `state` and `config` (a live sim or a replay). The session calls `view.onEvents(events)` after every `sim.step`, `view.render(alpha, frameMs)` once per frame, and adds no time to its accumulator while `view.simFrozen` is true (global freezes, A12). `render/loop.ts` `FixedStepClock` holds the B6 accumulator arithmetic. The view raises `ViewEvent`s (`view.on`) for the HUD: mount taps, emotes, denied commands, evolves, coins, match end. `ui` may not import `render` (B2), so the HUD takes the view through the structural `HudViewBridge` in `ui/hud/bridge.ts`, which `BattleView` satisfies. (DESIGN B2, B6)
- 2026-09-27 (feel config): `feel.config.json` satisfies the frozen `FeelConfig` and adds render-only fields (`RenderFeelConfig` in `render/feelConfig.ts`): per rule `flashTarget` (victim/screen/base), `flashAlpha`, `traumaGapMs` (base hits: trauma at most once per 0.5 s), `jitterPx` (heavy-hit victim jitter), `slowMo` and `globalExempt` (base destroyed); and a `tuning` block for numbers A12 states outside its table (ghost hold/drain, number spread and merge window, coin travel and pitch climb, sound gaps, music intensity increments, reduce-motion factors, seam drift, camera follow and zoom, death linger, telegraph length, 1-in-3 mech explosions). Rule keys are event keys the mapper derives (`hit.light`, `hit.heavy`, `death.unit|heavy|legendary|mech`, `power.impact`, `evolve.own|enemy`, `lastStand.fire`, `base.destroyed`, ...). Per-event ids use placeholders resolved by the mapper: `$spark`, `$hitSound`, `$attackSound`, `$dieSound`, `$spawnSound`, `$powerSound`, `$fanfare`. (DESIGN A12, B6)
- 2026-09-27 (event units): The view converts every sim position to lu, including `powerTelegraph.zone`, which the real sim emits in milli-lu like `x` (500 lu = 500,000). The canned fake stream still says `zone: 500`; requested a fix in `docs/requests/wp5-fake-telegraph-zone.md`. (DESIGN B3)
- 2026-09-27 (camera and layout): World y is lu with 0 on the ground line, which sits at 80% of the lane band's height. The fit scale is `min(band width / 1,560, band height / 330)`, so on very wide, short screens tall units and bases stay in the band and the world is centred. Pinch zoom (screens < 900 CSS px) keeps the ground line in place and grows upward; the follow target is the midpoint of the two ground front lines (a side with no ground units counts its gate). Air units fly at y = −118 lu (alternating −14 lu per air unit) above the depth rows. (DESIGN A2.1)
- 2026-09-27 (juice details): Coins that fly to the gold counter = bounty / 25 gold, clamped to 1-4. Hits from the same source on the same target within 380 ms merge into one number (a barrage reads as a few totals). The music intensity layer is a view-side estimate: each hit, heavy hit, death, base hit, power and own evolve adds a tuned amount, it decays 0.2/s and is pushed to audio at 4 Hz. Own evolves transpose +2, +2, +1, +1. Level trims: bronze at levels 4-6, silver 7-9, gold 10. Melee swing sounds play 80 ms before the impact frame. (DESIGN A12, A13)
- 2026-09-27 (presets): Auto starts High on desktop and Lite on mobile, drops to Lite when the average frame over 3 s exceeds 20 ms, never climbs back during a match, and ignores the first 1.5 s of frames (texture uploads and lazy bakes are not the steady frame rate). The particle cap is the preset's cap, never above the device cap in `feel.config.json` (600 mobile, 1,500 desktop). The view applies the particle cap, shadows and Legendary auras; the host applies `view.resolution(dpr)` (DPR ≤ 2, 1 in Lite). (DESIGN B6, B16)
- 2026-09-27 (HUD input): A press the HUD can already tell is invalid (unaffordable card, uncharged power, Evolve not ready, ...) gets the denied feedback locally with `ui_deny`; everything else is sent and a sim `commandRejected` flashes the element that last sent that command type (the view plays `ui_deny`). Mouse presses do not move focus onto HUD buttons, so Space always casts the power; a Tab-focused button keeps Space/Enter. Held keys do not repeat. A long press of 450 ms cancels a card's last queued instance. The power button turns into a drag after 12 px, only when charged and aimable (Stampede, Royal Decree, Nanite Surge and Paratroopers ignore the aim, WP2); releasing a drag off the lane cancels. The mount popover asks for a second tap to sell; Shift + click on a mount sells at once and the "+" mount buys at once (A2.12). The emote button honours `economy.emoteCooldownMs`. (DESIGN A2.9, A2.12, A9.2)
