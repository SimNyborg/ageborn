# Build decisions

Append-only log of decisions made where `docs/DESIGN.md` was ambiguous or had to change during the build. Add entries under your work package heading: date, the decision, and the DESIGN section it touches.

## WP0

- 2026-09-27: The repo is public and hosted on GitHub Pages (owner's choice, to keep hosting free). DESIGN B1 and C2/WP0 updated accordingly.
- 2026-09-27 (contracts): B15 `export declare function createSim / replayMatch / createBot` became the type aliases `CreateSim`, `ReplayMatch` (`src/contracts/sim.ts`) and `CreateBot` (`src/contracts/bot.ts`). A declared function in a real `.ts` module has no runtime value, so under `verbatimModuleSyntax` a value import of it would silently be `undefined`. Implementations export `const createSim: CreateSim = ...` (WP2) and `const createBot: CreateBot = ...` (WP3). Signatures are unchanged. (DESIGN B15, B10)
- 2026-09-27 (contracts): The combined B15 blocks "observation.ts and bot.ts" and "session.ts and platform.ts" are split into the separate files B14 lists. `src/contracts/index.ts` is a type-only barrel (`export type * from ...`); every contract module has zero runtime exports (a test checks this). Pixi and signals types are referenced only as type-level `import('pixi.js')` / `import('@preact/signals')`, as in B15, so the "contracts import nothing" rule (B2) holds at runtime. (DESIGN B2, B14, B15)
- 2026-09-27 (contracts): `Observation.units[].p` and `telegraphs[].p` use the same unit as `SimState` positions (milli-lu, B3), measured from the observer's gate. B15 only says "p relative to the observer". (DESIGN B3, B15)
- 2026-09-27 (fakes): `src/contracts/fakes/**` are test and dev helpers only; production code must not import them. `fakes/art.ts` imports `pixi.js` at runtime (C2/WP0 task 5 asks for Pixi Graphics rectangles), with a single `eslint-disable-next-line ageborn/layers` on that import. (DESIGN B2, C2/WP0)
- 2026-09-27 (fakes): The fake content uses the A5 table units (lu, ms, whole HP, gold), not compiled units; it is shape-correct `CompiledContent` for UI, render and wiring tests, never balance. Because `ages` and `formats` are total records, all five `AgeDef`s exist, but every fake format spans only Stone and Medieval and only those have cards. The fake economy uses `mountCosts: [0, 150, 350, 700]` (mount 1 free, A2.3) and `emoteCooldownMs: 3000` (DESIGN gives no value; WP1 must pick the real one). The fake `SaveDoc` reuses the Medieval loadout for ages without fake cards. The fake sim's canned stream uses B3 integer units (milli-lu, centi-HP, milli-gold); units do not walk on their own. (DESIGN A2.3, B3, C2/WP0)
- 2026-09-27 (scaffold): Toolchain pins (B1). TypeScript 6.0.3, not 7.0: typescript-eslint 8.70.1 supports `typescript >=4.8.4 <6.1.0`. Vite 8.3.1 with @preact/preset-vite 2.10.6 (peer range includes Vite 8; dev and build verified). Vitest 5.0.2, ESLint 10.11.0 (typescript-eslint supports it), @playwright/test 1.56.1 because its bundled Chromium is revision 1194, the one preinstalled in cloud sessions. @types/node 22.x to match the Node 22 runtime.
- 2026-09-27 (scaffold): Layer rules (B2) are enforced by a small local ESLint rule `ageborn/layers` in `eslint.config.js` that resolves `@/` and relative specifiers to their src layer, instead of `no-restricted-imports` string patterns (which cannot tell `contracts/fakes -> ../content` from a real `content` import). `LAYER_RULES` is exported for the tests/integrity import-graph test. Package allowances not spelled out in B2: `valibot` in content and save, `fflate` in save, `@preact/signals` in capsule. Test files (`*.test.ts(x)`, `*.bench.ts`, `test/` folders) are exempt from layer and determinism rules, since for example AI tests must run the sim. `import('pixi.js')` type annotations are allowed (contracts use them for view types).
- 2026-09-27 (scaffold): Determinism lint bans float literals in sim, ai, meta, core and content, except `src/content/raw/**`, which mirrors the Part A tables exactly (compile.ts converts to integers, B4).
- 2026-09-27 (scaffold): sfc32 follows PractRand (`tmp = a + b + counter++`), seeded with four xmur3 words of `"${seed}"`, no warm-up discards. Draws return uint32; `randInt` uses rejection sampling (no modulo bias). Core offers integer `isqrt` and a degree-based `sinDegBp`/`cosDegBp` lookup table since `Math.sin/sqrt` are banned in the pure layers.
- 2026-09-27 (scaffold): i18n files are `src/i18n/<namespace>.<locale>.json`, discovered with `import.meta.glob`. Nested objects flatten to dot keys; keys are global across files (each WP prefixes its own), duplicates warn in dev and the first file (alphabetical) wins. Missing keys fall back to EN, then to the key itself. Placeholders are `{name}`.
- 2026-09-27 (scaffold): Dev pages (`src/dev/<name>/page.tsx`) default-export a Preact component and may export `title`; `?dev=1#<name>` opens one. Dev pages are internal tools and exempt from the i18n rule. The game name "Ageborn" is a brand constant, not a string key.
- 2026-09-27 (scaffold): `npm run size` (tools/size.ts) counts index.html plus the entry script, modulepreload chunks and stylesheets referenced from dist/index.html, gzipped; fails above 3 MB, warns when all of dist exceeds 8 MB. Playwright runs against `vite preview` at /ageborn/ (Chromium only for now); `PW_CHROMIUM_PATH` overrides the browser binary.
- 2026-09-27 (raw content): Layout of `src/content/raw`. Each age file exports one `RawAgeTables` (`{ age, units, turrets }`, DESIGN table order); `powers.ts` exports `powers: PowerDef[]`; `economy.ts` exports `economy: EconomyRules` plus four raw-only tables: `ageScale` (A2.2 P and base HP, A2.4 thresholds; WP1's `ages.ts` adds palette, visual and music ids), `formats` (A2.10 as `FormatDef`, for WP1's `formats.ts` and the WP2 shim), `damageMods` (the A2.6 role-default mod lists, shared by the age files) and `battle` (A2.1-A2.11 and A5.1 numbers with no `EconomyRules` field: lane length, windup percents, train time per group, Brace/air knockback resist, mark ×1.2, heal pulse, modernise credit, final-age XP cap 1,200, Siege decay step, Stampede fallback p = 200, default projectile speeds). `types.ts` holds the raw-only types and `index.ts` aggregates everything as `raw: RawContent`. Units stay in table units (lu, lu/s, ms, whole HP and damage, gold, bp); `windupPct` stays a percent as in the contract. (DESIGN B4, B15)
- 2026-09-27 (raw content): Contract fields not in the Part A tables are filled by convention: `visualId` `unit.<slug>` / `turret.<slug>` / `power.<slug>` (A14.1); `nameKey`/`descKey` `card.<slug>.name` / `card.<slug>.desc` for units, turrets and powers (WP1 writes those keys in `content.en.json`); unit `sfx` from the A14.2 defaults (spawn by role group, `die_mech` for the mech tag else `die_bio`, so the Balloon Admiral dies with `die_bio`); power `sfx` from the A13 `pw_*` ids; `strongVs`/`weakVs` empty until WP1's counter matrix fills them; `trainMs` and `pop` from the A2.7 group tables. Every attack sets `windupPct` explicitly (melee 40, ranged 50, turret 0; "melee" = no projectile), so rider and secondary attacks are unambiguous. (DESIGN A2.7, A13, A14.1, A14.2, B4)
- 2026-09-27 (raw content): Tags. Every non-air unit also gets the `ground` tag (the table's Tags column only lists `air` for fliers), so each unit has exactly one of `ground`/`air`. The tutorial Training Dummy (listed under A5.6) is a Stone card (`age: 'stone'`, in `stone.ts`, `hidden: true`) so it never triggers the underdog bounty in the Stone-only tutorial; it is an Infantry-group unit with the Blunt role default, `dmgType` blunt. (DESIGN A2.6, A5.6)
- 2026-09-27 (raw content): Projectile speeds not in the A5.1 default list: projectiles whose card note says "arc" (Rock Tosser, Trebuchet, Bronze Cannon, Howitzer, Plasma Mortar, Grenadier lob) fly at the arc/lob speed 450 with `arc: true`, even when the A14.2 visual is a shell or cannonball; bee, bolt and goose use the arrow speed 650; log, bomb and gravity orb 450 (no arc); grapeshot 1,500 (musket class); chainshot and flak 1,200 (shell class). Instant effects: `fx.tongue`, `fx.pitch_pour`, `fx.beam_rail`, `fx.beam_laser`, `fx.arc_chain`. (DESIGN A5.1, A14.2)
- 2026-09-27 (raw content): Ability encodings. Aura statuses use `durationMs: 0`, meaning "while inside the aura" (recomputed each tick, B3 step 6). `resist.bp` is the share of damage resisted (Footman 2500 = 25% less), matching how knockback resist is expressed. Corsair's Boarding Hook is `firstHitBonus` with `multBp: 10000` and `knockback: -20`. Battering Ram: `damage: 10` (vs units), `vsBaseDamage: 160`. Balloon Admiral: `range: 40` (the ±40 lu drop window, same as `bomber.dropWindow`) and explicit `vsBaseDamage: 110`. Grumpy Toad uses `priority: 'backline'` plus `drag`; its "else the second-frontmost small or medium ground enemy" fallback is a sim rule. Gravity Well's `onHit` slow goes to every enemy inside its `pull` radius, not only the (at most 4) damaged ones. Repair Drone has `attacks: []` (Hits: none). Searchlight mark: `magnitudeBp: 2000`. (DESIGN A2.7, A5.2-A5.6)
- 2026-09-27 (raw content): Power encodings. Arrow Storm and Broadside state no jitter; A2.9 says jitter is 0 only for line patterns, so every even barrage uses the one stated value, ±20 lu (Meteor Shower); Carpet Bomber (line) uses 0. Orbital Lance `sweep.width` is the full beam width, 40 (±20 lu), consistent with Smoke Screen's `cloud.width` 350 being a full width. Nanite Surge: regen `magnitudeBp: 4000` is the share of max HP healed over the 4 s; the 150 shield is `amount` with `magnitudeBp: 0`. Stampede's start (frontmost unit or p = 200) and Paratroopers' p ≤ 1,050 clamp come from `battle.stampedeFallbackP` and `economy.powerZoneClamp`. (DESIGN A2.9, A5.7)
- 2026-09-27 (raw content): `economy.mountCosts` is `[0, 150, 350, 700]` (index i = mount i + 1; mount 1 free), as in the fakes. `economy.emoteCooldownMs` is 3,000 ms: DESIGN gives no player emote cooldown (only the bot's 20 s reply rule in A7.2). (DESIGN A2.3, A7.2)
- 2026-09-27 (raw content): `tests/fixtures/content` is a byte-for-byte copy of `src/content/raw` (plus a 3-line "frozen" header) taken in Phase 0. `src/content/raw/raw.test.ts` runs the same DESIGN-typed table checks (24 units, 11 turrets, 8 powers, collection shape, group prices, windups, speeds, sounds, economy, formats) against both. When tuning changes a raw number, update DESIGN and that test row, never the fixture. (DESIGN C2/WP0 task 8, B13)
- 2026-09-27 (verification): The fake content (`src/contracts/fakes/content.ts`) now follows DESIGN where it differed: Tuskback carries no Blunt mods (A2.6 gives them to Infantry melee only), the Pumpkin Head skin is Rare (A5.8), fake powers use the A13 sound ids `pw_stampede` / `pw_arrows`, and the fake skin id is the bare slug `pumpkin_head` (the `SkinDef.id` / `SideConfig.skins` value), with `@` used only in the visual id `unit.bonker@pumpkin_head`, matching `src/core/ids.ts` `skinnedVisualId`. (DESIGN A2.6, A5.8, A13, A14.1, B5)
- 2026-09-27 (verification): `tests/integrity/lint-rules.test.ts` lints small virtual files through the real `eslint.config.js` to prove the layer rule (for example `pixi.js`, `preact` or `render` imported from `src/sim`, Node built-ins in `core`) and the determinism rules (`Math.random`, `Math.sin`, `Date`, float literals, `for...in` in sim, ai, meta, core and content) fire, and that allowed imports, `render` and `content/raw` floats pass. It sits in WP12's `tests/integrity` because B13 lists the layer check as an integrity test; WP12 owns it from Phase 1. (DESIGN B2, B13)
- 2026-09-27 (verification): `.gitignore` also covers `dist-ssr/`, `*.tsbuildinfo`, `blob-report/`, `playwright/.cache/`, `.eslintcache`, `*.local` and `.claude/settings.local.json` (the last was only ignored by the container's global git config).
