# Build decisions

Append-only log of decisions made where `docs/DESIGN.md` was ambiguous or had to change during the build. Add entries under your work package heading: date, the decision, and the DESIGN section it touches.

## WP0

- 2026-09-27: The repo is public and hosted on GitHub Pages (owner's choice, to keep hosting free). DESIGN B1 and C2/WP0 updated accordingly.
- 2026-09-27 (contracts): B15 `export declare function createSim / replayMatch / createBot` became the type aliases `CreateSim`, `ReplayMatch` (`src/contracts/sim.ts`) and `CreateBot` (`src/contracts/bot.ts`). A declared function in a real `.ts` module has no runtime value, so under `verbatimModuleSyntax` a value import of it would silently be `undefined`. Implementations export `const createSim: CreateSim = ...` (WP2) and `const createBot: CreateBot = ...` (WP3). Signatures are unchanged. (DESIGN B15, B10)
- 2026-09-27 (contracts): The combined B15 blocks "observation.ts and bot.ts" and "session.ts and platform.ts" are split into the separate files B14 lists. `src/contracts/index.ts` is a type-only barrel (`export type * from ...`); every contract module has zero runtime exports (a test checks this). Pixi and signals types are referenced only as type-level `import('pixi.js')` / `import('@preact/signals')`, as in B15, so the "contracts import nothing" rule (B2) holds at runtime. (DESIGN B2, B14, B15)
- 2026-09-27 (contracts): `Observation.units[].p` and `telegraphs[].p` use the same unit as `SimState` positions (milli-lu, B3), measured from the observer's gate. B15 only says "p relative to the observer". (DESIGN B3, B15)
- 2026-09-27 (fakes): `src/contracts/fakes/**` are test and dev helpers only; production code must not import them. `fakes/art.ts` imports `pixi.js` at runtime (C2/WP0 task 5 asks for Pixi Graphics rectangles), with a single `eslint-disable-next-line ageborn/layers` on that import. (DESIGN B2, C2/WP0)
- 2026-09-27 (fakes): The fake content uses the A5 table units (lu, ms, whole HP, gold), not compiled units; it is shape-correct `CompiledContent` for UI, render and wiring tests, never balance. Because `ages` and `formats` are total records, all five `AgeDef`s exist, but every fake format spans only Stone and Medieval and only those have cards. The fake economy uses `mountCosts: [0, 150, 350, 700]` (mount 1 free, A2.3) and `emoteCooldownMs: 3000` (DESIGN gives no value; WP1 must pick the real one). The fake `SaveDoc` reuses the Medieval loadout for ages without fake cards. The fake sim's canned stream uses B3 integer units (milli-lu, centi-HP, milli-gold); units do not walk on their own. (DESIGN A2.3, B3, C2/WP0)
